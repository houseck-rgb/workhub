# 하루장 — 이월형 일정 다이어리

## 폴더 구성 (모두 같은 위치, 폴더 없음)
```
index.html
manifest.json
sw.js
icon-180.png
icon-192.png
icon-512.png
icon-original.png
```

## GitHub 업로드 방법
1. GitHub 저장소 (예: username.github.io 또는 일반 저장소) 로 이동
2. "Add file" → "Upload files"
3. 이 안의 파일 7개를 전부 선택해서 한 번에 업로드 (폴더 없이 파일만 그대로 올리면 됩니다)
4. GitHub Pages 설정에서 배포하면 `index.html`이 자동으로 첫 화면이 됩니다

## 모바일 설치
- 안드로이드(Chrome): 접속 시 뜨는 "설치" 배너 → 설치 버튼
- 아이폰(Safari): 공유 아이콘(⬆︎) → "홈 화면에 추가"
